# No typing source and license notice

This is a compatibility-only Revenge Next port of the Classic `No typing`
plugin published by redstonekasi.

- Audited Classic artifact: <https://vd-plugins.github.io/proxy/redstonekasi.github.io/vendetta-plugins/no-typing/>
- Artifact SHA-256 from its manifest: `5f1d76d9b6bc14e708b7b9ff6cd165c6da2cc038470f5c386c1fabe0ad959fad`
- Original source: <https://github.com/redstonekasi/vendetta-plugins/tree/50c6afcca1c2390db494292a2bf238bd0b34b352/plugins/no-typing>
- Original license: BSD 3-Clause License

Only the module lookup, patching, and lifecycle compatibility code was adapted
for Revenge Next. The original behavior—replacing both `startTyping` and
`stopTyping` with no-op functions—is unchanged.
